Installing streamlit-pdf-feedstock
==================

Installing `streamlit-pdf-feedstock` from the main channel can be achieved by:

```
conda install streamlit-pdf-feedstock
```

It is possible to list all of the versions of `streamlit-pdf-feedstock` available on your platform with `conda`:

```
conda search streamlit-pdf-feedstock
```
